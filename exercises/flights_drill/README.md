# Флайты DRILL — на скорость

Короткие задачи «база + маленькое усложнение». Цель — **скорость**: читать задачу
и сразу видеть форму запроса, без раздумий. Решай по 2–5 минут, не залипай.

## Метод «увидел → форма» (тренируй его)
Читая задачу, сразу спрашивай себя:
1. **Что вернуть?** одно число / список / по группам → `SELECT` + нужен ли агрегат.
2. **Откуда?** одна таблица или несколько → `FROM` / `JOIN`.
3. **Какие строки?** «где / только / за период» → `WHERE`.
4. **Считаем по группам?** «по каждому / сколько у каждого» → `GROUP BY`.
5. **Условие по группе?** «где сумма/число > …» → `HAVING`.
6. **Порядок / сколько** → `ORDER BY` + `LIMIT`.

Прогони этот чек-лист в голове ДО написания — через пару десятков задач станет автоматом.

## Решай пачками
Реши 3–5 подряд и пришли вместе — так быстрее и виднее прогресс по скорости.
