# ЭКЗАМЕН 1 — SQL на оценку

8 задач, **100 баллов**. Подсказок в заданиях нет — только условие и требуемые столбцы.
Это проверка того, что усвоилось: базовые агрегаты, JOIN, подзапросы, окна, CTE и **ловушки**.

## Правила

1. Решение пишешь в тот же файл под строкой `-- решение:`.
2. Справочником пользоваться можно (`_ПАТТЕРНЫ_SQL.md`, свои конспекты) — это не про зубрёжку.
3. Гуглить синтаксис можно. Просить готовое решение — нет, иначе оценка не имеет смысла.
4. Решил 3–4 — присылай пачкой, не жди все 8.

## Как я оцениваю

| Критерий | Вес | Что смотрю |
|----------|:---:|------------|
| **Правильность** | 60% | запрос возвращает верный результат на верных данных |
| **Ловушки** | 20% | целочисленное деление, NULL в агрегатах, фан-аут, границы периода, недетерминированный `LIMIT` |
| **Читаемость** | 20% | осмысленные алиасы, форматирование, нет лишних `GROUP BY`/подзапросов, число остаётся числом |

**Шкала:** 90+ отлично · 75–89 хорошо · 60–74 удовлетворительно · <60 — разбираем тему заново, без обид.

## Схема (что есть в базе)

```
bookings   (book_ref, book_date, total_amount)
airports   (airport_code, airport_name, city, country)
airplanes  (airplane_code, model, range, speed)
seats      (airplane_code, seat_no, fare_conditions)
routes     (route_no, departure_airport, arrival_airport, airplane_code, days_of_week, validity)
flights    (flight_id, route_no, scheduled_departure, actual_departure, status)
segments   (ticket_no, flight_id, fare_conditions, price)
timetable  (view: flight_id, route_no, scheduled_departure, actual_departure,
                  departure_airport, arrival_airport, status)
```

Классы обслуживания: `Economy`, `Comfort`, `Business`.
