# Флайты PRACTICE — разминочный тир (как базовая папка)

По одному навыку на задачу, без многошаговости. Для беглости: чтобы базовые
конструкции писались на автомате. База: `demo`, схема `bookings`.

## Чек-лист

| № | Файл | Навык | Готово |
|---|------|-------|:------:|
| 1 | `01_airports_by_country.sql` | WHERE + ORDER BY | ☐ |
| 2 | `02_flights_by_status.sql` | GROUP BY + COUNT | ☐ |
| 3 | `03_top5_bookings.sql` | ORDER BY DESC + LIMIT | ☐ |
| 4 | `04_bookings_above_avg.sql` | скалярный подзапрос в WHERE | ☐ |
| 5 | `05_cities_multi_airport.sql` | GROUP BY + HAVING | ☐ |
| 6 | `06_planes_above_avg_range.sql` | подзапрос + сравнение | ☐ |
| 7 | `07_destinations_from_city.sql` | JOIN (×2) + DISTINCT | ☐ |
| 8 | `08_passengers_on_flight.sql` | JOIN по цепочке | ☐ |

Быстрые, приятные, без ловушек. Прогоняй пачкой, коммить, отмечай галки.
Если какая-то покажется слишком лёгкой — просто иди дальше, это разминка.
